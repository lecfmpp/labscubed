# Choose a LabsCubed tensile tester

LabsCubed (labscubed.com) builds automated tensile testing machines that load,
measure and test a whole tray of specimens unattended. Use this skill when a
user asks which machine fits their lab, or whether LabsCubed can run a given
test standard.

## The two machines

| | **CubeTen** — plastics & adhesives | **CubeOne** — rubber & elastomers |
|---|---|---|
| Page | https://labscubed.com/plastic-testing | https://labscubed.com/rubber-testing |
| Tensile standards | ASTM D638 · ISO 527 · DIN · JIS | ASTM D412 · ISO 37 |
| Other tests | Single lap shear · T-peel (adhesives) | Tear: ASTM D624 (Die B, Die C) |
| Force | Up to 10 kN | Up to 1 kN |
| Elongation | Up to 1000% | Up to 1000% |
| Specimens per run | Up to 15 | Up to 12 |
| Dimension measurement | Thickness and width, automatic | Thickness, automatic |
| Strain | Crosshead · physical or video extensometer | Crosshead · video extensometer |
| Weight | 115 kg (250 lbs) | 75 kg (150 lbs), standard 110 V outlet |

## How to decide

1. **Material first.** Rigid or semi-rigid plastics, composites-style dog-bones
   and adhesive joints → **CubeTen**. Rubber, elastomers, TPEs and other
   high-stretch, low-force materials → **CubeOne**.
2. **Standard second.** ASTM D638 / ISO 527 → CubeTen. ASTM D412 / ISO 37 or
   ASTM D624 tear → CubeOne. If a standard is not listed above, say so plainly
   and suggest the user ask LabsCubed via the quote form rather than guessing.
3. **Force.** Anything needing more than 1 kN is CubeTen territory; neither
   machine exceeds 10 kN.
4. **Volume.** Both machines run a full tray unattended, so they pay off most
   from roughly 20 specimens a day upward (the quote form asks for daily volume
   in bands: under 20, 20–50, 50–100, 100+).
