# IndexNow key file

`26a1e497ebee437f9e70afe2431719a1.txt` must stay in `public/` and keep serving its
own key as plain text at:

    https://www.labscubed.com/26a1e497ebee437f9e70afe2431719a1.txt

IndexNow fetches that URL to prove we control the host before accepting any
submission. Delete or rename the file and every submission silently stops being
honoured.

The same value is stored in Supabase Vault as `indexnow_key`, which is what the
`blog-publish` edge function reads. If you ever rotate the key, both have to
change together.

NOTE: this only works once `/` is served by this site. While `labscubed.com` is
still proxied to Webflow, the key file is unreachable and IndexNow will reject
submissions.
